# ABA Data — quick guide

**Install:** open the app link in Safari → Share → **Add to Home Screen**. Open it from the Home Screen icon
(that keeps your data safe from Safari's clean-up and lets it work with no signal).

## 1. Add a client
Tap **+**, type the first initial and the school initial (e.g. K, S). Optional note like "Gr 3" if two
students share initials. Sort the list **By school**, **A–Z** or **Recent**.

## 2. Add targets (once per client)
Client → **Targets** → **Add target**. Name it, pick the data type, set the interval if it has one, and
optionally paste the operational definition (it goes into the Excel file). Targets are remembered, so
every future session is pre-loaded and the graphs line up over months.

## 3. Take data
**Start session** → untick anything you're not collecting today → **Start now**.

| Tile | What to do |
|---|---|
| Frequency | Tap the tile each time |
| Duration | Tap when it starts, tap when it stops |
| Latency | *Instruction given*, then *Responded* (or *No response*) |
| Partial interval | Tap once if it happens during the interval |
| Whole interval | Tap if the behavior stops during the interval |
| MTS | When the screen edges flash, look up and tap **Yes / No** |
| PLACHECK | When it flashes, set how many are engaged, **Save** |
| Interval rating | When it flashes, tap a number |
| ABC | Tap → pick A, B, C chips → **Save ABC** |
| Compliance | Tap the result after each instruction |
| DBR | Tap → rate the three items 0–10 (end of activity or session) |

- **Undo** at the bottom reverses the last tap. **Pause** stops the clock and intervals.
- Every tap is saved immediately. If the phone locks or the app closes, open it and tap the orange
  **Session in progress** banner.

## 4. Email it
**End** → **Email Excel** → pick Outlook or Mail. The Excel file is attached. The subject
(`Data Collection - K S`) is filled in by Mail; in Outlook it's already copied — long-press the subject
line and **Paste**.

## 5. Graphs
Client → **Graphs**. Each target has its own graph; choose the measure with the chips. Tap a point to see
that session. **Phases** adds a dashed phase-change line (e.g. *Baseline* → *Token board*); data lines
don't connect across phases. Also: an ABC summary with a
"possible function" hint.

## Back up
Settings → **Back up…** now and then (save to Files/iCloud Drive or email it to yourself). **Restore**
merges a backup into this phone — use it for a new phone.
